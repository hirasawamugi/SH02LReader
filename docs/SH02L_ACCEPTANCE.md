# SH-02L 阅读器验收清单

日期：2026-10-18
关联计划：[SH02L_READER_PLAN.md](SH02L_READER_PLAN.md)。
工程根目录：工作区下的 `SH02LReader/`；设备资料位于 `device/`，后续源码、工具和产物均在此工程内维护。
当前状态：M0 实体按键与 M1 TXT 核心流程已验证；详见 [M0 验证记录](M0_VALIDATION.md) 和 [M1 验证记录](M1_VALIDATION.md)。这里同时列有 M2—M4 的标准；未勾选项目包含尚未覆盖的组合条件，不能按部分通过视为全部完成。

每次记录 APK 版本、SHA-256、源码提交、设备系统/固件、测试方式、结果和证据。结果限定为“通过 / 失败 / 待测 / 不适用”，并区分 JVM、模拟器和 SH-02L。真机发布前使用与交付 APK 一致的 release 构建。

## A. 构建与启动（M0 起）

- [x] 固定工具链可以从源码构建；APK 签名验证通过（M0）。
- [ ] 新应用与旧 AA 阅读并存；安装新应用不会改变旧书架数据。
- [ ] 首次安装、权限尚未授予、权限被拒绝后均能进入可操作界面。
- [x] 真机冷启动 20 次成功，无启动闪退、ANR 或无法定位的焦点（M0 样例工程）。
- [ ] 全部应用内界面不使用触控也能完成核心操作。

## B. 按键事件和导航（M0 起）

- [ ] 记录方向键、确认、数字键、星号、井号、F1—F4 的 Down/Up/Repeat；键值匹配项目记录。
- [x] 普通 F2（keyCode 132）和已知异常 F2（UNKNOWN + scanCode 753）产生相同应用动作（UNKNOWN 为构造事件，JVM / 两个 API 27 环境）。
- [x] 一个短按执行一次动作；按下和抬起不会分别翻页或执行两次（自动测试、M0 用户手测）。
- [x] 两次连续正常短按都被识别，没有被全局防抖吞掉（JVM）。
- [x] 连续翻页、移动条目可重复；菜单、返回、添加书签不因长按连续触发（JVM / M0 手测方向长按；M1 正文确认不重复）。
- [x] 打开和关闭菜单的同次抬起事件不会作用于下层页面（JVM / 原生界面）。
- [ ] 合盖、切到后台或系统弹窗出现后，恢复时没有遗留长按、翻页或焦点跳动。
- [ ] 应用实际收到的 F1—F4 在书架、阅读、菜单、设置中不误启动相机、邮件和浏览器。
- [ ] 挂断、清除等系统行为按设备实测记录；应用内始终有 F2/F4 或菜单提供的替代返回入口。
- [x] 蓝色高亮对应真正可确认的当前项；确认执行的对象与可见高亮一致（M0/M1 原生界面与正式包文件导入）。
- [ ] 空书架、单本、多个条目和列表边界均无焦点死区。
- [ ] 进入目录/设置/书签后返回，恢复原焦点条目和滚动位置；条目已删除时选择合理相邻项。
- [x] 首次和重复打开菜单，上下区域及子菜单都能立即操作（M0/M1 原生回归）。
- [ ] “打开菜单 → 移动 → F2 → 再打开”重复 100 次，F2 每次只处理最上层。
- [ ] 组合执行至少 1000 次方向、确认、菜单和返回动作，没有越界、重复弹层或无法返回。
- [ ] 系统权限弹窗、系统文件选择和系统输入法分别完成无触控操作验证。

## C. TXT 内容与分页（M1 起）

- [ ] UTF-8 无 BOM/有 BOM、UTF-16LE/BE 带 BOM、GB18030/GBK 均能正确读取。
- [ ] 编码误判可以手动纠正，原始文件字节保持完整。
- [x] 测试中文多字节字符跨读取块边界、代理对、混合中英文、标点、emoji 和组合字符（M1 JVM / 原生排版）。
- [x] CRLF/LF、跨块 CRLF、空行、无末尾换行、超长行和超长无换行段落不丢字或失控分配内存（M1 JVM / 50 MiB 原生测试）。
- [x] 小文件逐页遍历的逻辑文本范围连续且无重叠；前后翻页能返回同一正文位置（M1 三种字号、760 页 / 环境）。
- [ ] 章节标题跨读取块、无章节标题、标题在首行、章节很短和单章超长均能处理。
- [ ] 首尾页、首尾章、空文件和无法解码文件有明确状态，不越界或闪退。
- [x] 1 / 10 / 50 MiB 文件完成导入和阅读；50 MiB 文件不 OOM，主线程可返回与取消（规模与排版原生测试；Activity 取消路径另有回归）。
- [ ] 快速切书、切章、改变字号并取消加载时，旧任务不会覆盖当前书籍或当前布局。

## D. 进度、书签与恢复（M1 / M2 起）

- [x] 正常返回书架再打开、重新启动应用，恢复正确书籍和正文位置（M1 原生回归 / 正式包）。
- [x] 停止翻页并确认进度已提交后强制停止进程，重开恢复最后提交的位置（M1 正式包，UTF-8 / GB18030，两个 API 27 环境）。
- [ ] 在写入窗口内异常中断时可打开数据库，恢复最后完整提交记录；允许的进度回退被记录。
- [ ] 合盖与展开、进入后台后系统回收、阅读中来电或系统界面切换均不损坏阅读状态。
- [ ] 修改字号、字体、行距、边距和信息栏后，原锚点文字仍在当前页或相邻一屏以内。
- [ ] 书签在排版修改、重启和升级后仍可跳转到对应内容。
- [ ] 图书重名、重复导入、原文件变化和索引缓存失效不会串用进度。
- [ ] 导入取消、存储空间不足、缓存损坏、内存卡移除和来源权限撤销都能恢复操作。
- [ ] 升级 APK 后书架、进度、书签和设置保留；数据库迁移失败不破坏原有有效数据。

## E. 日常功能与窗口（M2 起）

- [ ] 导入、打开、目录、章节跳转、书签、设置、搜索、进度跳转均可只用按键完成。
- [ ] 数字输入、中文输入、确认和取消不会意外触发阅读快捷键。
- [ ] 字号和亮度有明确边界；亮度调整只作用于本应用窗口。
- [ ] 字体文件损坏、缺字或无法读取时能回退系统字体。
- [ ] 首次打开菜单、重复打开菜单、切换主题均不意外显示状态栏或改变正文区域。
- [ ] 空结果、无目录、无书签和书籍末尾都可返回，没有无响应确认项。
- [ ] 搜索、导入和索引均可取消；关闭页面后不继续更新已销毁界面。
- [ ] 根菜单可明确退出，F2 不造成误退出；快捷键帮助与实际动作一致。

## F. 性能与发布（M3）

- [ ] 签名 TXT release APK ≤ 5 MiB；报告包含实际字节数和依赖列表。
- [ ] 10 MiB TXT 索引完成后稳态总 PSS ≤ 80 MiB；同时记录 50 MiB 文件结果。
- [ ] 至少 10 次冷启动，100 本书的书架到可操作 P95 ≤ 2.5 秒。
- [ ] 至少 100 次列表移动，正确高亮绘制 P95 ≤ 100 毫秒。
- [ ] 至少 300 次就绪页面翻页，P95 ≤ 100 毫秒；跨章节读取单独报告。
- [ ] 真机连续阅读 2 小时，并穿插菜单、设置、合盖和恢复，无崩溃、ANR、持续增长的内存或错误正文。
- [ ] 静置、后台和取消任务后无无意义的高频重绘、预取或常驻服务。
- [ ] 导入前后和升级前后数据抽查通过；所有关键失败项已修复或明确限制发布范围。
- [ ] 发布目录只有该版本唯一正式 APK，并附 SHA-256、来源提交、构建信息、验证记录和已知限制。

## G. EPUB 接入（M4）

- [ ] 记录 SH-02L 实际 ABI、Android System WebView 版本和字体环境。
- [ ] 针对选定正式版引擎验证 EPUB 2/3、中文排版、图文、目录、链接和重排定位。
- [ ] 方向键、F 键、菜单关闭与焦点恢复沿用共用规则，无 WebView/原生组件事件冲突。
- [ ] EPUB 自己的定位、书签和排版变化恢复正确，TXT 位置格式不被混用。
- [ ] EPUB 格式能力和未支持内容有明确说明；暂不宣称 DRM 或复杂格式全覆盖。
- [ ] 包体和内存预算包含引擎及相关进程，单独报告新增开销。
- [ ] TXT 的关键回归重新通过，已有 TXT 用户数据不受影响。
