## EPUB 后端与实机修正

选择本工程有界 Java ZIP/XML 模型 + 系统 WebView，未复制或捆绑 Readium/CoolReader 引擎。Readium/CoolReader 仅作架构/工具链候选筛选；原件和资源身份保留，不转 TXT。依据及许可声明见 NOTICE。

真机初轮暴露 Harmony XML factory 不支持桌面 SAX 功能开关，已用声明检查 + 空实体解析器兼容处理，保留外部实体隔离并补回归。WebView 67 已完成显示、按键移动、内链及返回、搜索、重排与重新打开的实际检查。截图发现系统字体缩放叠加，已用统一 ReadingStyle 和固定 WebView textZoom 修正，并调整标题行距。
