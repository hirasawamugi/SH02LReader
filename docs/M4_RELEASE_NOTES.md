# M4 整合试用版

版本：0.6.0-m4，versionCode 9，正式包名与签名沿用 M3。大迭代以后按 M5、M6 递增。

- 01：重复导入先识别再解析，复用既有进度与书签；按书选择正文缓存，核验原件，保留当前阅读书并分别报告处理结果。
- 02：列表左右边距对称、细滚动条占用边距；帮助页去掉滚动条及无效软键占位。左右翻列表页，目录 F1 按序号定位；清理页 F3 处理所选。长书名跑马灯只播放一轮。
- 03：五种界面配色、七个颜色角色、自定义静态书架背景、缩放对齐与遮罩，独立草稿支持预览、保存和放弃。保存处理后的屏幕尺寸资源，清理未引用文件。正文配色独立保留。
- 04：8 键切换纯阅读，保留正文边距和现有渲染器；F4 直接返回书架。颜色变化与排版分开，连续模式切换保留逻辑锚点。

M4 没有加入网络、动态背景、自动扫描或常驻服务。05、06 后续推进，其余暂缓。

安装采用同签名覆盖升级，保留书库、进度、书签、设置和外部原件。验证与实际清理范围见 [验证记录](M4_VALIDATION.md)，操作细节见 [使用指南](USAGE.md)。
