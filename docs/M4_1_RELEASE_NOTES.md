# M4.1 修补版 · 0.6.1-m4.1

针对 M4 试读反馈的五项修补。正式包名仍为 `com.sh02l.reader`，versionCode 10，同签名覆盖安装，保留书库、定位、书签、阅读设置和外观设置。

## 变化

1. F1/F3 菜单去掉重复的“关闭菜单”选项，打开时第一项位于顶部并获得焦点；F4 或再次按当前菜单键关闭。
2. 背景使用分块解码，保留屏幕需要的源图细节，避免与小封面共用采样策略造成“先缩小、再放大”。仍只保存屏幕尺寸静态图；不保留另一份大原图。
3. 底部按键提示使用透明底色，书架图片能够连续显示到底部，弹出菜单则继承菜单面板底色。
4. EPUB 保留完整原件校验，复用最近一本书的不可变书籍信息和目录。仅内存保留、估算最多 2 MiB；更换书籍、退出或系统内存回收时释放，不保留 ZIP 文件句柄、正文和图片，也不写入磁盘缓存。共用的路径与空白正则预编译，减少大目录的重复分配。
5. 菜单和设置使用小型上下提示，仅在相应方向确有隐藏内容时出现；短菜单不显示。书架、目录、书签、搜索结果等长列表保留细条，颜色跟随当前主题，对称边距不变。

## 实测与使用提示

SH-02L 上使用手机内《蛊真人》的临时副本（19,663,431 字节）测量：返回书架后再次打开，M4 约 5.2 秒，M4.1 约 1.5–1.7 秒；本轮首次打开约 5.4 秒。首开仍需要解析和初始化 WebView，不承诺所有书籍秒开。这是有限次数的 debug 样本，具体分段、边界和验证见 [验证记录](M4_1_VALIDATION.md)。

M4 已保存的背景只有处理后的图片，丢失细节不能从现有文件恢复。升级保留当前背景；要改善旧图清晰度，请在“界面外观”重新选择一次原图并保存。

未加入动态背景、动画、后台服务或周期性扫描。本轮为本地整合试用，不自动发布 GitHub。
