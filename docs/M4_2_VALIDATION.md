# M4.2 复查与验证

复查基线：M4.1 / ca07513。设备 SH-02L / Android 8.1，正式应用数据不用于破坏性测试。修补版本：0.6.2-m4.2 / code 11。

## 发现与复现

`AppearanceFeatures.save()` 的异步完成操作通过 `host.back()` 退出编辑器，但保存期间 0 键仍可压入帮助层。这样完成时弹出的是帮助层，编辑器仍留在栈中。

新增 `M41ReviewTest` 使用现有存储事务锁暂停自有调试数据的保存，确定性模拟慢存储，再按 0。修补前四项检查中三项通过，该项失败：预期 MENU，实际 THEME_EDITOR。没有填满设备存储，也没有改动正式版文件。

修正由外观模块报告处理状态，帮助入口在这一短暂阶段保留当前编辑器并显示提示。图片处理仍允许 F4 取消；保存开始后沿用原有防中断规则。完成之后重新检查 0/F4 帮助开关，避免永久屏蔽。
