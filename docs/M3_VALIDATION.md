## TXT 原书复现与定点回归

正式 M2.5 直接打开用户原书即可观察第 23 节：页面正文为四个空格加“而方源只能自己想办”，共 13 个 UTF-16 单元。实际页首 73715、页末 73728 = 9 × 8192；下一页首字为“法”，没有额外源换行。确认是读取块边界提前短页，非仅凭夹具推测；观察后已返回原页。

证据 tools/logs/m3/txt-before.xml、txt-next-before.xml、txt-locator-before.txt，图片 [原有短页](images/m3/txt-short-before.png)。未提取或改写原书字节。

新增块边界夹具初次 RED 为 expected 8259 / actual 8192；章节置顶夹具 RED 为 expected 8401 / actual 8360。修正后与既有多字号逐字连续/反向一致性共 3 项真机通过，3.822 秒，instrumentation-m3-txt-green-corrected.txt。

首次“GREEN”误用了只重建测试 APK 的 test-apk 构建，主 debug APK 仍旧；保留旧失败日志。已增加 focused 构建同时重建 debug 与 test APK，后续按实际产物核对。初次章节夹具恰在分块起点，已移到块内后观察有效失败。

## EPUB 与写入边界

延迟图片夹具有效 RED 为加载中 alpha expected 0 / actual 1，坏图路径原先正常。第一轮未进入图文检查的两个超时是触控模式导致列表没有初始选择，恢复方向键模式后获取有效结果；不作为 EPUB 缺陷。

图片/坏图、重排重开、延迟字体及三项持久化检查的初轮批次 8 项中 7 项通过。一项直接片段链接失败已采到 DOM 在 #mid / 第 18 页、native 仍 offset 0 且 ready=true。受信脚本改为将链接交还受限原生导航，跨资源/同资源直接点击返回及章节快捷键定点复核两项通过，18.79 秒；对应日志 instrumentation-m3-link-fix.txt。

三项持久化场景包括：EPUB 定位字段拒写后旧记录整体有效，恢复写入后新记录整体有效；导入文件发布与书目提交间的中断现场可重试且来源保留；重建缓存提交前/后保留两代现场，复开后与数据库已提交一代一致。未修改存储产品代码，也不把模拟状态称作硬件断电测试。
