# M2.5 变更说明

版本：`0.4.0-m2.5` / code 7。一次整合交付，沿用应用 ID 与签名，可覆盖 M2 保留书库。

## 日常操作

| 按键 | 功能 |
| --- | --- |
| F1 | 书架：所选图书的封面、重命名、原件导出、删除；正文：目录、书签、返回书架、搜索、跳转及格式专属动作 |
| F2 | 书架/正文导入 TXT 或 EPUB，取消后返回原处 |
| F3 | 通用菜单：阅读与界面设置、导入、存储管理、按键说明、诊断、退出 |
| F4 | 返回/关闭当前层；正文返回书架，书架根层不直接退出 |

输入用 F3 确认、F4 取消。F1/F3 可替换同层菜单，再按同一菜单键关闭；未选书时 F1 提示先选书。菜单关闭在首项，默认选中常用动作，危险项在末尾并确认。移除封面、导出封面仅在存在封面时显示。

可选列表首尾循环并跳过说明项；正文分页、帮助滚动、数字设置与编辑光标保持各自边界。书架循环当前批次，跨批仍使用上一批/下一批。保留选中行在视口内移动和返回后的像素位置。

底栏改为两行四键提示；帮助页重新调整键帽、说明、间距与字体层级，并写明当前页面和输入规则。

## EPUB

支持无 DRM 的可重排 EPUB 2/3：原件导入/导出、元数据及内置封面、目录、分页/切章、内部链接和跳转返回、搜索及续查、书签、字号/行距/边距/字体/主题，以及内容锚点保存和重开。EPUB 不转换成 TXT，不显示文本编码纠正。

使用系统 WebView 的 HTML/CSS 排版。书内脚本、外部网络、本地文件/内容提供程序和主动媒体访问关闭。当前不支持固定版式、交互脚本、多媒体及加密资源（包括含混淆字体的加密声明）。

边界：原件及归档总展开上限各 256 MiB，最多 20,000 个归档条目；单篇正文 4 MiB、单资源 8 MiB。过大或异常文件会拒绝/隔离对应资源。其他真实出版物及其他机型的兼容性仍需后续试读，不把本次夹具验证解释为所有 EPUB 都已兼容。

## 后续维护

按键配置、页面动作与提示共用规则；schema、私有文件操作、导入导出和阅读会话分工明确。TXT 也已迁入通用文档/界面契约，新增机型和格式有固定入口。Java 排版工具固定版本并校验。详见 [代码结构](CODE_STRUCTURE.md)。

数据库升级至 v3，旧 TXT ID、offset、书签标签和外观保留；EPUB 保存独立版本化定位。原件、导入文件夹及外部 Books 的数据边界沿用原约定，删除图书仍需确认。

实际设备、验证证据、发布哈希和正式升级状态见 [M2.5 验证](M2_5_VALIDATION.md)。M3 完整规模与耐久测试按试读结果安排。
