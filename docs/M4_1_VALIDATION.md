# M4.1 验证记录

基线：M4 / 573b5e5。设备：SH-02L，Android 8.1 / API 27，540×960，系统 WebView 67。修补版本：0.6.1-m4.1 / code 10。

## 定位与修正依据

- 菜单含“关闭菜单”却默认选中第二行，并将第二行滚到顶部。移除冗余行，初始选择统一为 0，保留按键关闭。
- 720×1280 背景转为 540×960 时，旧 4 MiB 工作预算可能把源图先采样到 360×640，再放大。新分块解码按显示比例决定采样，不按整张源图大小过度降采样。工作输出仍不超过约 1.98 MiB，加单块位图受 4 MiB 检查约束；这不等于整个解码器或应用的 PSS 上限。
- SoftKeyBar 原先强制画不透明底色，现继承父容器背景。菜单滚动提示不新增动画、计时器或周期重绘。
- “正在打开图书…”发生在原件校验、EPUB 元信息解析及 WebView 创建阶段。对比 M3→M4，这段完整校验和重复解析流程没有新增；M4 的样式/重排调整不是本次采样的主要等待来源。
