# M3 变更说明

版本：0.5.0-m3 / code 8。沿用 com.sh02l.reader 与现有证书，保留书库、进度、书签和设置。

## 阅读改进

- TXT 将读取窗口与显示分页分开，窗口末尾未完成的页面接续下一段内容，不再在约 8192 单元边界提前结束。
- TXT 从目录或上一/下一章跳到章节起点时，标题位于正文第一行；沿用已有章节索引，不需要重新导入。
- EPUB 在首次文档中即应用阅读样式；图片/字体就绪并完成可绘制状态同步后再显示和发布定位，减少图片页先显示再调整的过渡。
- EPUB 同文件锚点点击与跨文件链接均交给原生跳转历史，避免浏览器已经滚动而阅读位置仍停留原处。

TXT 仍为有界排版：通常 8192、最多 16384 UTF-16 单元/布局，三个布局窗口与至多 1024 个偏移范围；没有整书预排。数据库仍为 v3，定位格式不变。按键和菜单语义沿用 M2.5。

## 验证与边界

补充三类独立存储现场检查：进度记录整体性、导入文件已发布但书目未提交的重试、缓存替换在数据库提交前后的一致性。存储产品实现没有为这些测试新增通用故障框架。

只进行集中相关回归与少量响应/内存采样，不包含 100/1000 本书、完整 P95、50 MiB 或长时压力。合盖、来电、一般后台回收恢复及长期试读由用户日常观察。

EPUB 首次图片解码仍有实际开销；本轮改善显示时序，不承诺所有出版物或复杂图形都无停顿。原有固定版式、DRM、脚本和多媒体范围不变。系统文件选择器的创建文档界面兼容问题未在本轮扩展处理。

实际证据、内存样本与最终发布/升级状态见 [M3 验证](M3_VALIDATION.md)。
