# M1.5 主题、书架与实体按键界面

版本：`0.2.5-m1.5`（versionCode 3），应用 ID：`com.sh02l.reader`。

- 米白、柔白、暖炭灰三种界面主题；正文配色独立，5 键继续循环正文颜色。
- 同级列表行等高，12 dp 圆角、柔和选中填色，移除左侧蓝条与条目横线。名称单行显示，仅当前选中且页面可见时滚动。
- 书架支持纯文字、小书标和单列独立封面，默认小书标；设置分为界面外观与正文阅读，立即保存，逐层返回恢复焦点。
- 自定义静态 JPEG/PNG/WebP 封面，统一方向并居中裁剪，保留原图；缩略图后台采样、可见范围加载和有界缓存。
- TXT 与封面共用文件夹、手机/内存卡和系统文档选择入口，默认复制，可核验并有删除能力的来源提供移动。先完整提交并校验，再尝试删除来源；不能删除时明确保留来源。
- 图书菜单可导出原 TXT，有自定义封面时可导出原图，保持原始字节。私有书库随卸载/清除数据移除，请按需导出。
- 原生绘制 SH-02L 实体按键图，方向盘、数字中列和底部罗马键对齐。0 反复开关；CENTER 不退出；F2/F4 关闭帮助；上下滚动说明。帮助覆盖正文，保留菜单焦点、阅读 View 和锚点，导入继续运行。
- 拒绝已关闭页面、过时文件选择、权限与导出结果的回调，避免干扰新流程。

沿用 M1 的 TXT v1 定位、数据库和独立签名，正常覆盖安装保留书架、原件、书签、进度及显示设置。本次用户明确要求清理手机上的 M1 及全部用户数据，已先卸载 M1；升级保留验证使用隔离模拟器生成的夹具，不取用手机旧资料。

验证详见 [M1_5_VALIDATION.md](M1_5_VALIDATION.md)。M2 的搜索、输入、书籍管理、书架数据分页和完整低存储进度重试，以及 M3 性能/长期试读仍待实施；MATVT 唤醒兼容性继续跟踪。
