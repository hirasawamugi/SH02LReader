# 使用指南

适用于 M4.1 / 0.6.1-m4.1。主要验证设备为 SH-02L / Android 8.1；其他手机的物理键标识可能不同，以应用按键说明为准。

## 安装与升级

本轮整合试用包见 `dist/v0.6.1-m4.1/`；既有 M4、M3 安装包保留作版本记录。正式应用包名为 `com.sh02l.reader`；使用相同签名的后续版本覆盖安装可保留书架、进度、书签和设置。卸载会移除应用私有数据和应用导入文件夹。

自行编译优先使用独立的 debug 包 `com.sh02l.reader.debug`，可以与正式版并存。新生成的发布签名不能覆盖原签名的正式版，构建方式见 [构建指南](BUILDING.md)。

## 导入图书

按 F2 打开导入页，选择 TXT 或 EPUB。可以浏览手机存储、内存卡、系统文档入口，或进入“应用导入文件夹”。共享存储首次使用时按提示授予文件权限。

- **复制导入**：保留来源文件，将阅读所需原件保存到私有书库。
- **移动导入**：原件提交和完整性校验成功后删除选中的来源文件；来源及所在目录需要允许写入。没有删除权限时使用复制。

通过 USB 传书可以使用公共 `Books` 目录，或以下应用导入目录：

```text
/storage/emulated/0/Android/data/com.sh02l.reader/files/import/
```

先打开一次 F2 导入页创建应用目录，再使用支持指定目标路径的传输工具放入文件。放入文件后仍需手动选择导入，不会自动加入书架。该目录在卸载应用时移除；公共 `Books` 可用于保留来源文件。

## 按键

| 场景 | 按键 | 动作 |
| --- | --- | --- |
| 书架 | ↑ / ↓，确认 | 选择和打开图书 |
| 书架 / 正文 | F1 | 所选书籍菜单 / 阅读菜单 |
| 书架 / 正文 | F2 | 导入 TXT / EPUB |
| 普通页面 | F3 | 通用菜单：设置、存储、帮助、诊断、退出等 |
| 普通页面 | F4 | 返回 / 关闭；正文返回书架 |
| 输入 | F3 / F4 | 确认 / 取消 |
| 正文 | ↑ / ← | 上一页 |
| 正文 | ↓ / → / 确认 | 下一页 |
| 正文 | 1 / 3 | 上一章 / 下一章 |
| 正文 | 2 | 目录 |
| 正文 | 4 / 6 | 调小 / 调大字号 |
| 正文 | 5 | 切换阅读配色 |
| 正文 | 7 / 9 | 调整应用窗口亮度 |
| 正文 | 8 | 开关纯阅读模式，F4 直接返回书架 |
| 正文 | ＊ / ＃ | 阅读设置 / 书签 |
| 普通页面 | 0 | 开关按键帮助 |
| 帮助 | ↑ / ↓，0 / F4 | 滚动，关闭 |

输入时数字键用于输入，0 不打开帮助。列表 ↑/↓ 首尾循环，←/→ 按可见页移动并在边界停止；目录 F1 输入目录序号定位条目。正文翻页和帮助滚动按内容边界停止。书架根层 F4 不退出应用，退出在 F3 菜单中并需确认。

## 阅读与管理

M4.1 的 F1/F3 菜单从第一项开始，关闭使用 F4 或再次按当前菜单键。短菜单没有滚动标记，超出屏幕时用小箭头提示上下还有选项；目录等长列表保留细进度条。

F1 阅读菜单提供目录、书签、搜索、百分比跳转和返回书架等操作。TXT 目录/切章跳到章节起点时标题置顶；EPUB 的内部链接使用统一跳转历史，菜单可返回跳转前位置。

阅读设置可调整字体、字号、配色、行距、边距和信息栏。可导入不超过 8 MiB 的 TTF / OTF 自定义字体，当前保留一份；字体加载失败时回退系统字体。

书架 F1 菜单可改名、设置封面、导出原件和删除。删除图书会删除其私有原件、缓存、封面、进度和书签，保留外部来源文件。F3 的存储管理可以查看占用、删除选中书籍、管理导入文件夹和重建 TXT 缓存。

## 常见问题

- **TXT 乱码**：在阅读菜单选择编码纠正。支持自动、UTF-8、UTF-16LE、UTF-16BE 和 GB18030；编码变化按比例近似映射位置与书签，落点可能略有变化。
- **TXT 提前换页**：M3 已修正读取窗口边界造成的异常短页。若仍出现，记录书名、章节、前后文字与阅读设置，便于定点分析。
- **EPUB 图片页等待**：系统 WebView 需要解码图片和排版；M3 会等待页面稳定后显示，复杂页面仍可能有等待。固定版式、DRM、书内脚本和多媒体不在当前范围。
- **文件不能移动**：来源文件或目录可能没有删除权限，可以复制导入。内存卡和系统文档提供程序的权限由系统决定。
- **系统导出界面无法操作**：SH-02L 上观察到系统“创建文档”页面的按键兼容问题，现阶段需按具体系统界面判断；这不等同于原件已成功导出。

需要反馈问题时，可从 F3 进入按键诊断并选择“保存诊断记录”，导出位置在诊断页显示。提供版本、发生步骤和必要的诊断片段即可，避免上传整本图书或无关个人数据。

## M4 外观与清理

F3 → 界面外观：上下选项，左右调整配色、书架样式、遮罩；确认进入自定义颜色、图片选择或预览。预览 F4 返回草稿，外观根页 F3 保存、F4 放弃。自定义颜色输入六位 RGB，如 `39C5BB`；输入页 F3 仅确认颜色，不保存整个外观。

背景支持静态 JPG / PNG / WebP，原图最大 32 MiB，支持裁剪铺满或完整显示及五种对齐。只保存处理后的屏幕尺寸图片，原图不被移动或删除。保存后要重新裁剪需再选择原图。背景仅用于书架；菜单与设置使用界面配色，正文保持独立配色。

M4.1 改为分块处理原图，避免先缩得太小再放大。M4 已保存的模糊背景无法恢复丢失细节，请在外观中重新选择一次原图并保存。底部按键提示背景透明。

EPUB 重新打开时仍完整核验原件；同一次使用中只复用最近一本书的目录和书籍信息（估算上限 2 MiB），不写入磁盘缓存。退出、内存紧张或切换书籍后可能重新解析，因此大型 EPUB 首次打开仍有等待。

纯阅读隐藏标题、信息栏、软键提示及空通知；保留正文边距和重要错误提示。原信息栏偏好仍在阅读设置中，退出纯阅读后生效。没有增加常亮、动态背景或后台扫描。

存储管理中按确认勾选，F3 打开处理确认，默认选中取消。正文缓存可按书选择，核验私有原件后才清理；当前阅读书自动保留，清理结果区分成功、跳过、失败。再次打开时按需重建。重复导入保留原书名、进度与书签，并跳过重复的格式解析和索引生成。
