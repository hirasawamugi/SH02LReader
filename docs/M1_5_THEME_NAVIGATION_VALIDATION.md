# M1.5 主题与列表导航修订验证

日期：2026-10-19（Asia/Shanghai）。版本 `0.2.6-m1.5` / versionCode 4，正式 ID `com.sh02l.reader`。本次沿用正式证书覆盖安装，包含此前的共享存储权限补丁。

## 修订结果

- 原“柔白”改为“白色”，背景与面板均为 `#FFFFFF`；米白背景改为 `#F1E7D2`、面板 `#FAF3E5`，搭配较暖的墨色文字与选中底色。主题编号保持，界面与正文仍可独立设置。
- 所有通用列表先在页面内移动选框，越过上下边界才滚动至新行完整可见；反向移动先在当前页面内移动选框。关闭帮助、返回父文件夹时恢复所选条目及像素位置。
- 每次刷新不再把选中项重新对齐到顶部。保存滚动位置时排除尚未更新的旧选中 View，并即时记录待布局的目标偏移，处理快速“下→帮助”的连续按键。
- 右侧预留 12 dp 的独立区域，使用 3 dp 圆角细滚动条，分别适配深浅主题，并固定在右侧。

按实际选中底色混入 4% 强调色后的结果计算 sRGB 对比度：三主题主文字最小值约 7.91，次要文字最小值约 4.62。检查了 SH-02L 的三主题、三书架样式、帮助及设置截图；纸色与白色区别清晰，文字与滚动条没有互相覆盖。最终纸色偏好仍可在日常试读中调整。
