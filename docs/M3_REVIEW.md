# M3 集中差异自查

按用户认可的轻量计划，仅做一次作者集中差异检查，没有派生实现/审查子代理。范围为 M2.5 基线 21ba48e 以来的阅读、测试和发布差异；它不是独立第三方审查。

核对结果：

- TXT 的页首/页末仍是 UTF-16 内容定位；窗口尾部未完成页不发布，继续读取后排版。布局上限与偏移缓存上限明确，取消检查和过期任务保护保留；格式专用对象未泄漏回 Activity。
- 章节起点来自既有索引。跳转、邻页和字号变化已有定点场景，未写入源文件或改数据库定位格式。
- EPUB 初始样式与后续配置共用 Java 生成规则，避免两套 CSS 漂移；最终绘制回调检查 epoch 后才发布 ready/定位，关闭或切章后的迟到回调不覆盖新状态。
- 内部 reader-nav 路由先核对随机当前书籍 host，再限定目标为同 host 的 https 资源，并走归档解析。外部网络、文件、内容提供程序、书内脚本和多媒体限制保留。
- 存储产品实现未改动；新测试不操作正式书库。缓存两代现场绕过正常 finally 以模拟持久中断状态，模拟范围有明确说明。
- 最终采样只输出少量主进程 PSS 与按键到 ready 的粗略等待；WebView 多进程关闭。没有把测试轮询耗时当实际绘制 P95，未恢复历史长时或规模要求。
- 发布脚本加入 M3 文档/图像/阶段映射，沿用签名与来源一致性校验；本轮正式核对不调用包含强停恢复的默认旧冒烟整套流程。

没有发现额外需要扩展本轮范围的阻塞问题。关联检查发现的同文档锚点跳转已修正并复核，最终整合结果和正式升级状态以 M3_VALIDATION 为准。

保留边界：首次图像解码开销、其他出版物/机型、系统创建文档选择器与用户日常合盖/来电/长期使用反馈不由本轮结果替代。执行中的工程裁定完整记录于 M3_PROGRESS。
