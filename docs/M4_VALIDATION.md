## SH-02L 轻量采样

设备 Android 8.1 / API 27，540 × 960；测试使用独立 debug 包、自有 TXT/EPUB 和几何背景图片。原生测试框架等待事件与绘制，所以以下是有限次数的观察，不能当作帧率或 P95。

| 检查 | 实测 |
| --- | --- |
| EPUB，20 次纯阅读切换 + 20 次帮助开关 | 7065 ms 合计；主进程 PSS 84405 KiB |
| TXT，同样的切换 | 2372 ms 合计；主进程 PSS 75394 KiB |
| TXT 前台静置 30 秒 | CPU 累计增加 106 ms；PSS 74782 KiB |
| TXT 后台静置 30 秒 | CPU 累计增加 5 ms；PSS 73882 KiB |

每种格式先连续翻页 20 次，再切换并检查返回后的锚点及同一视图对象。纯阅读打开菜单/帮助不改变正文视口。没有新增常亮、亮度改变、后台扫描、动画或轮询；跑马灯限一轮。测试框架为避免设备休眠使用临时常亮标志，正式应用未增加该策略。上述短样本不证明长期续航改善，合盖/来电和长时间阅读继续通过日常试用观察。

背景输出最多 518400 像素（约 1.98 MiB ARGB），单次解码工作位图预算 4 MiB，加上当前和草稿图约 8 MiB 的应用持有引用上限；这不是整个应用的 PSS 限制。图片线程最多一个执行和一个待执行任务。保留原有 TXT 16384 字符布局、3 个窗口/1024 个偏移范围与单 WebView 约束。
