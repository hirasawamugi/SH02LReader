# M2 日常阅读与存储管理

日期：2026-10-19。版本：`0.3.1-m2`，versionCode 6，正式 ID `com.sh02l.reader`。

- 正文菜单新增搜索和百分比跳转。搜索为区分大小写的字面匹配，每批最多 100 条，可继续下一批；结果显示位置和上下文。
- 原生输入框支持数字及系统输入法，F3 确认、F2/F4 取消；数字 0 不再在输入时打开帮助。系统中文输入法仍需用户在真实输入法中试用。
- 正文设置增加行距、左右/上下边距，系统/衬线/无衬线/等宽字体，以及不超过 8 MiB 的 TTF/OTF 字体导入。自定义字体只保留一份，可移除；读取失败回退系统。
- 支持自动、UTF-8、UTF-16LE、UTF-16BE、GB18030 编码重建。保留原始字节，编码变化时按阅读比例近似映射进度和书签，位置可能略有变化。
- 图书支持改名和确认删除；删除包含私有原件、正文缓存、索引、封面及对应进度和书签，保留外部来源文件。
- 书签支持跳转、改名和删除；封面可单独移除并恢复默认图。
- 存储管理显示 TXT 原件、正文缓存、封面、自定义字体、导入目录及可用空间，支持按占用查看、勾选多本删除和单独选择 import 文件清理。
- 清理正文缓存先核验原件，保留当前阅读书，重开自动重建。损坏缓存可从私有原件恢复。
- 书架按每批 50 条元数据查询，上一批/下一批可按键操作，返回按书籍 ID 恢复批次与选中项。
- 数据库 v1→v2 显式增加排序索引，覆盖升级保留书库。删除和重建使用恢复目录；进度失败保留最新待保存位置，释放实际分配的 256 KiB 应急空间并有限重试。
- 拆分导航状态、输入框、阅读设置、图书/存储操作与阅读功能，TXT 会话通过统一 seek/move 契约接入。

原 TXT 和封面原图导出继续提供；导出不包含书签、进度等整库备份，也不会自动删除私有书库。复制导入留下的来源文件只在用户选择清理后删除；移动导入仍先提交并完整核验。

本轮按用户要求精简重复视觉排列与压力测试，优先验证数据隔离、升级、缓存恢复、输入和定位。实际结果见 [M2 验证](M2_VALIDATION.md)。EPUB、M3 长期性能和日常试读不包含在本轮完成声明中。
