> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

## Global Constraints

- 目标 SH-02L：Android 8.1 / API 27，540×960，240 dpi，约 360×640 dp；已有真机 font_scale=1.3。布局读取当前窗口、密度和字号，不硬编码物理像素补丁。
- 采用原生 Views/Canvas，无常驻动画或额外 WebView 运行时；所有必要操作可用实体键完成，焦点与实际确认对象一致。
- 总体清爽纸感，默认暖米白；界面主题与阅读配色独立，5 键只切换阅读配色。首次安装均为暖色，升级把 M1 `theme` 迁移为两份初值。
- Palette 逐角色采用设计第 3 节的柔白/米白/暖炭灰色值，禁止各页另造主题色。暖色背景 `#F4F1EA`、面板 `#FFFCF6`、主字 `#2D3033`、次字 `#696A66`、强调 `#3C6688`、选中底 `#E4EBF0`、分隔 `#D8D4C9`。
- 标题 20 sp、主列表 17 sp、辅助与软键 12 sp，外边距 12/10 dp、圆角 4 dp、操作行至少 52 dp、侧标 3 dp；文字随系统字号增高，不通过缩小文字填满固定框。
- 三种书架样式为纯文字/小书标/独立封面，默认小书标；始终单列，继续阅读只出现一次，无封面使用统一默认封面。
- 设置分层、立即生效、自动保存，F2 恢复父层焦点；保留字号、亮度、8 键信息栏和 5 键配色等现有功能，不添加未实现的 M2 入口。
- TXT 位置仍为归一化 UTF-16 偏移 v1；保留原书籍 ID、原件、索引、书签和最后提交的进度。外观回退不得清库，必要的数据库变化显式迁移。
- 封面接受静态 JPEG/PNG/WebP，统一 EXIF 方向，单次工作位图预算 4 MiB、来源上限 32 MiB；有界采样与缩略图缓存，禁止全库解码。
- 移动是完整导入、校验、持久提交之后才删除有权限且未变化的来源；失败、取消或无法可靠验证时保留来源并准确报告。
- M1 `0.2.0-m1` APK、tag、签名证据保留。实施交付使用 versionCode 3 / versionName `0.2.5-m1.5`，本轮不修改版本。
- 不改相邻旧 `../AAReader`，不输出或提交签名密码，不修改手机全局字号/亮度，不填满用户日常手机测试低存储。

### Task 5: 共用安全复制/移动与导入空间保护

**Files:**
- Create: `reader-core/src/main/java/com/sh02l/reader/core/importing/ImportSource.java`, `reader-core/src/main/java/com/sh02l/reader/core/importing/ImportCoordinator.java`, `reader-core/src/main/java/com/sh02l/reader/core/importing/SpaceGuard.java`
- Modify: `reader-core/src/main/java/com/sh02l/reader/core/text/TextImporter.java`, `app/src/main/java/com/sh02l/reader/BookRepository.java`, `app/src/main/java/com/sh02l/reader/CoverStore.java`
